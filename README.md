# St Georges App

A React web application for St Georges, bootstrapped with Create React App.

## Tech Stack

| Layer | Technology |
|-------|------------|
| Frontend | React 18 |
| Build Tool | Create React App |
| Testing | Jest, React Testing Library |
| Styling | CSS Modules / styled-components |
| Analytics | web-vitals |

## Local Setup

```bash
# Clone the repo
git clone https://github.com/JonasAmidu/stgeorgesapp.git
cd stgeorgesapp

# Install dependencies
npm install

# Start the development server
npm start
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Available Scripts

| Script | Description |
|--------|-------------|
| `npm start` | Runs the app in development mode |
| `npm test` | Launches the test runner in watch mode |
| `npm run build` | Builds the app for production to `build/` |
| `npm run eject` | One-way eject from CRA configuration |

## Key Features

- React 18 with functional components and hooks
- Responsive UI with CSS Modules
- Web vitals tracking for performance monitoring
- Jest + React Testing Library for unit and integration tests
